# v0.6 Implementation Plan

## Milestones

1. Reliability hardening
- Fix initial-commit diff collection for staged files and empty files.
- Add positive tests for import-graph ordering.
- Ensure batched planner fallback still respects `max_commits`.

2. Artifact layer
- Treat cached plans as the source of truth for release-facing outputs.
- Keep artifact generation deterministic and independent from live LLM calls.
- Stabilize JSON output shapes for automation.

3. v0.6 commands
- `intentra release-notes`
- `intentra risk-report`
- `intentra changelog`
- Lightweight ticket linking from `--ticket` and branch-name detection

4. UX polish
- Clearer command help and examples
- Better diagnostics for missing or stale cached plans
- Documentation refresh after command behavior settles

## Testing Plan

1. Unit tests
- Artifact generation from fixed cached plans
- Ticket detection and footer enrichment
- Planner and context reliability regressions as they are fixed

2. Contract tests
- JSON schema stability for release notes, risk reports, changelog output, explain, and doctor

3. Integration tests
- Cached-plan happy path for new commands
- Missing-plan and stale-plan behavior
- PR/ticket integration behavior

4. Fixture coverage
- Add canonical cached-plan fixtures for v0.6 artifact outputs
- Keep replay-style regression coverage for deterministic planner behavior
