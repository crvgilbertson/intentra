# v0.5 Code Review

Review of all v0.5 changes for potential problems.

## 1. Import-graph ordering (`engine/context/import_graph.go`)

- **BuildImportGraph**: Returns error when `root == ""`; planner passes `ec.RootPath` (can be "" in replay/test). Fallback path is taken. ✓
- **OrderCommitsByImportGraph**: Nil graph or empty `FileToPackage` returns early; no reorder. Planner only sets `OrderingStrategy = "import_graph"` when `graph != nil && len(graph.FileToPackage) > 0`. ✓
- **computePackageLayers**: Recursion only follows packages present in `imports` map; no cycle risk in Go. ✓
- **Path consistency**: Planner builds `hunkToFile` with `filepath.ToSlash(h.FilePath)`; `FileToPackage` keys are slash-normalized. ✓

**Verdict**: No issues.

---

## 2. Risk scoring (`engine/validators/risk.go`, `cmd/plan.go`)

- **Disabled / empty areas**: Returns nil. ✓
- **pathMatch**: Error from `filepath.Match` is ignored (`matched, _`); invalid patterns simply don’t match. Acceptable for 0.5. ✓
- **Path normalization**: `filepath.ToSlash(fp)` in risk ensures Windows paths match. ✓
- **Score 0**: When risk is enabled and areas exist but no patterns match, we currently return `&CommitRisk{Score: 0, Level: "low"}`. That adds a risk block to every commit. **Fix**: Return nil when `score == 0` so “no risk” stays absent from the plan. ✓ (applied below)
- **hunkToFile in plan.go**: Built from `ec.Hunks`; same source as commit hunks, so no missing entries. ✓

**Verdict**: One small behavior fix (return nil when score 0).

---

## 3. Atomicity profiles (`engine/atomicity/`, planner, apply)

- **EffectiveMaxCommits**: Handles `base <= 0` (default 20). ✓
- **NormalizeProfile("")**: Returns `"balanced"`. DefaultConfig doesn’t set `Atomicity.Profile`; zero value is fine. ✓
- **Planner**: Sets `trace.AtomicityProfile` in `clusterHunks`; used for clustering cap and trace. ✓
- **Apply cache**: `atomicityStale` requires `cached.Trace != nil && cached.Trace.AtomicityProfile != ""`. Old plans with nil/empty trace don’t force replan. ✓
- **allowStalePrompts**: Does not override atomicity; replan when atomicity changes. ✓

**Verdict**: No issues.

---

## 4. Plan --analyze (`cmd/plan.go`)

- **buildAnalyzeReport**: Uses `uniqueFiles`; report has commits, files, rationale, risk. ✓
- **printAnalyzeReport**: Prints risk only when `c.Risk != nil`; no nil deref. ✓
- **--analyze --json**: Outputs `analyzeReport` with `Commits` only (no full plan). Documented. ✓

**Verdict**: No issues.

**Verdict**: No issues.
